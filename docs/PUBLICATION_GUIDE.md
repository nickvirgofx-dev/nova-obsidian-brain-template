# Publication Guide

Before publishing this template:

1. Replace placeholder project names if needed.
2. Keep examples synthetic.
3. Run `safety/PUBLIC_EXPORT_SCRUB_CHECKLIST.md`.
4. Confirm there are no private paths, emails, secrets, logs, or personal project names.
5. Commit locally.
6. Create/push the GitHub repository only after explicit approval by the owner.

Do not publish:

- private vault notes;
- raw chat logs;
- runtime logs;
- account data;
- API keys or tokens;
- machine-specific paths;
- paid-service automation;
- browser-account actions.
