# Setup Guide

## 1. Copy The Template

Copy `vault-template/` to your own workspace and rename it.

Example:

```text
your-workspace/obsidian-brain/
```

## 2. Create A Runtime Folder

Create a separate folder for generated files, external clones, logs, reports, screenshots, and caches.

Example:

```text
your-workspace/agent-runtime/
```

Do not put large runtime files inside the Obsidian vault.

## 3. Open In Obsidian

Open the copied vault folder in Obsidian.

Start from:

```text
01_AGENT_START_HERE.md
```

## 4. Customize Placeholders

Replace:

- `<VAULT_ROOT>`
- `<RUNTIME_ROOT>`
- `<PROJECT_NAME>`
- `<TODAY>`
- `<USER_PREFERENCE>`

Keep placeholders until you know the real value.

## 5. Add Your First Project

Use `PROJECT_INTAKE_ROUTER.md` before creating a project folder.

Projects belong under:

```text
10_PROJECTS/<PROJECT_NAME>/
```

Each serious project should have:

```text
README.md
CURRENT_STATE.md
TASK_BOARD.md
TASK_CHECKLIST.md
DECISION_LOG.md
HANDOFF.md
```
