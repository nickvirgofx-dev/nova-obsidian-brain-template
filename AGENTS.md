# Agent Bootstrap

This repository is a public-safe Obsidian brain template.

Use memory as orientation, not final truth. Current user instructions, real files, tests, and runtime evidence outrank stored notes.

## Start Here

Read this first inside the copied vault:

```text
01_AGENT_START_HERE.md
```

Do not automatically read every linked file. Start with compact context, then open only the specific files needed for the task.

## Core Rules

- Do not hard-delete memory without explicit approval.
- Do not rewrite stable memory broadly.
- Preserve before compacting, moving, archiving, or restructuring important notes.
- For substantial work, state a compact context contract before meaningful edits.
- Frame serious tasks with Goal, Rider, done condition, verification, stop rule, and recommended intelligence.
- Ask fewer questions for small clear work; ask one focused question at a time for large, risky, or ambiguous work.
- Before meaningful actions, classify the action as `allow`, `warn`, `review`, or `block`.
- Stop after two same-root-cause failures and report exact command/action, error, evidence checked, and next safer check.
- Keep raw sources separate from processed notes.
- Do not scan `50_TASKS/INGESTION/raw/` or `50_TASKS/INGESTION/wiki/` wholesale.
- Runtime outputs belong outside the vault under `<RUNTIME_ROOT>`.
- Record meaningful completed work in `50_TASKS/AGENT_WORK_LOG.md`.
- Stop before deploy, public push, auth, payment, secrets, OS repair, browser-account actions, MCP registration, hooks, global config changes, database/index migrations, or risky automation.

## Suggested Context Flow

1. Read `01_AGENT_START_HERE.md`.
2. Read `_INDEX.md`.
3. Read project `CURRENT_STATE.md` and `TASK_BOARD.md` only when the user names a project.
4. Inspect real files before editing or making final claims.
5. Sync results back into the relevant project notes.

## Public Safety

This template must stay generic. Do not add private paths, personal emails, API keys, private project names, raw logs, or copied private vault content.
