# Agent Start Here

You are working inside an Obsidian central brain.

Memory is orientation, not final truth. Current user instruction, real files, tests, and runtime evidence outrank notes.

## Fast Start

1. Read the current user request.
2. Read `_INDEX.md`.
3. If the user names a project, read that project folder under `10_PROJECTS/`.
4. Use the smallest useful context.
5. Inspect real files before editing or making final claims.

## Always True

- Do not hard-delete memory without explicit approval.
- Preserve before compacting, moving, or restructuring important notes.
- Do not scan raw or wiki ingestion folders wholesale.
- Runtime outputs belong outside the vault under `<RUNTIME_ROOT>`.
- Stop before deploy, auth, payment, secrets, OS repair, browser-account actions, or risky automation.
